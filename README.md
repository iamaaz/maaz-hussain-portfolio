# Maaz Hussain — Personal Portfolio

A personal portfolio for my work and learning in web design and frontend development.

**Live website:** [iamaaz.github.io/maaz-hussain-portfolio](https://iamaaz.github.io/maaz-hussain-portfolio/)

## About

I’m studying for an MSc in Computer Science at York St John University and developing my skills in frontend development. I enjoy designing and building webpages, and I’m learning by creating projects and sharing the process here.

## Built with

- HTML
- CSS
- JavaScript
- React and ThreeUI for the interactive Matrix Junction WebGL background

## Run locally

Open `index.html` in a browser. The fonts and interactive background load from external CDNs, so an internet connection is required for the full experience.

## Project structure

- `index.html` — portfolio content and page structure
- `styles.css` — responsive layout and visual styling
- `script.js` — navigation interactions and Matrix Junction setup
